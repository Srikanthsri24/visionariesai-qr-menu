# VisionariesAI Hotel — QR Menu

Futuristic React digital menu demo for a 5-star hotel experience.

## Run locally

```bash
pnpm install
pnpm run dev
```

Open `http://localhost:5173/menu`. For phone scanning, keep the phone on the same Wi-Fi and open the Network URL printed by Vite. The in-app QR automatically uses the current host URL.

## Included

- Responsive premium hotel menu UI
- Promotion banner and hotel branding
- Signature, starters, pure veg, non-veg, main course, breads & rice, desserts, and beverages
- Veg/non-veg filters, search, item quantities, and live table basket count
- QR modal plus `public/visionariesai-menu-qr.png` for printing
